# UGNAY UI icon kit

Import into Figma

1. Unzip the pack.
2. Drag the SVGs you need from the icons folder onto the canvas.
3. Turn each icon into a component if it will repeat. Recolor the vector stroke in Figma.
4. Open icon-reference.svg to see all 24 symbols and their default colors.

## Size and placement

- 24 × 24 px source frame with 2 px strokes, rounded caps and rounded joins.
- Use 24 px for standalone interface icons, 20 px for most controls, and 16 px beside status labels.
- Use a 44 × 44 px clickable target for icon-only controls. Give each one an accessible name.
- Pair every diagnostic icon with visible status text.
- The chevron points down by default. Rotate it 180 degrees for the expanded state.

## Color roles

| Role | Stroke | Suggested background |
| --- | --- | --- |
| Primary actions | #1757A0 Bubbles blue | #EAF4FF pale blue |
| Report accent | #A52558 Blossom pink | #FDEDF4 pale pink |
| Responded | #1D6A3D Buttercup green | #EAF7E7 pale green |
| Diagnostic finding | #9A5B00 dark amber | #FFF3DA pale amber |
| Not tested | #52647A slate | #E8EEF4 neutral fill |
| Scan or export error | #A92A36 red | #FDECEE pale red |
| General utility | #14263D navy | #F4F7FA canvas |
| Icons on navy or filled blue | #FFFFFF white | #14263D navy or #1757A0 blue |

The on-dark folder contains white versions of the main navigation and action symbols.
“No ping response” uses the amber clock. The red error icon marks failed operations.
